# Assets

The original game has no asset files: everything is drawn in code (tank masks, maps, palettes, themes, logos,
text). The port keeps it that way. Content is generated from the original's code, and art is drawn by the DS
code the same way the Python draws it.

| Asset | Source | Licence / notes |
|---|---|---|
| All game content: 113 tank designs (11×6 masks + materials), 131 ammo types, 137 maps, 90 home themes and their layers, 266 shop items, 20 tournament levels, 50 missions, 10 tickets, the Martyr script and cinematics, whispers, cheat codes, unlock registry, AI profiles, colour palettes, story text | `core/gen/content_data.c` + `content_enums.h`, generated by `tools/gen_content.py` from `reference/terminaltanks.py` | the original game's content, by ethanlabs101 |
| Terminal font, 5×8 px | `source/gen/font_data.c`, generated by `tools/gen_font.py` | ASCII/Latin glyphs from **Spleen 5x8** by Frederic Cambus, BSD-2-Clause (`assets/font/LICENSE.spleen`). Box-drawing and block elements are generated so they tile cell to cell; the game's symbols (hearts, coins, credits, stars, arrows and the like) are drawn by hand in `gen_font.py` |
| Big logos, digits | drawn at run time from the original's block-letter tables (`ui.c`) | original |
| Battlefield, tanks, shells, explosions, particles, skies, backdrops, RPS hands, artifacts, the mage | drawn at run time (`render.c`, `particles.c`, `backdrop.c`, `sprites.c`, `scn_match.c`) following the original's drawing code | original |
| ROM icon `assets/icon.bmp` (32×32, 16 colours) | drawn for this port (a green tank under a starry night sky, generated once with PIL) | this port |
| Sound | PSG square-wave beeps generated by the DS sound hardware (`platform.c`) | no samples |

Nothing else is bundled: no BIOS, firmware, fonts or images from other games. The build uses the BlocksDS SDK
(libnds, dswifi; zlib/MPL-2.0 licences) and its prebuilt ARM7 core. The test harness links melonDS (GPL-3.0); it
is a development tool only and is not part of the ROM.

## Regenerating

```sh
python3 tools/gen_content.py     # needs reference/terminaltanks.py; imports it, runs no game loop
python3 tools/gen_font.py        # needs assets/font/spleen-5x8.bdf
```

Both generators are deterministic: re-running them on the committed inputs reproduces the committed files byte
for byte.
