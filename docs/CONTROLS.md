# Controls

The original is played on a keyboard and turns keys into a small set of actions (`Action`: UP, DOWN, LEFT, RIGHT,
CONFIRM, FIRE, BACK, PAUSE, OTHER + the raw key). The DS port maps buttons to the same actions, so every screen
behaves as in the original. Every screen can also be driven entirely by touch.

## Buttons (everywhere)

| DS | Original | Action |
|---|---|---|
| D-pad | arrow keys / W A S D | move, aim |
| L or R **held** + d-pad | Shift + arrows / capital WASD | coarse step (5° / 5 % in battle) |
| A | Enter (CONFIRM) / Space (FIRE) | confirm / fire |
| B | Esc | back |
| START | P | pause menu (Esc also opens it in battle, as in the original) |
| X, Y, SELECT, L, R (pressed) | letter keys | screen-specific, see below |

Held d-pad directions auto-repeat (after ~0.27 s, then every ~0.07 s).

## Battle

| DS | Effect |
|---|---|
| ← → | barrel angle (L/R held: 5° steps) |
| ↑ ↓ | power (L/R held: 5 % steps) |
| A | fire |
| X | skip the turn to charge the SPECIAL attack (only with the SPECIAL rule) — the original's **X** |
| START or B | match menu: resume / restart / exit |
| Touch | ◄ ► angle, ▲ ▼ power (hold to repeat), FIRE, CHARGE (special), START MENU |

Practice range: **Y** toggles the coach panel, **SELECT** goes to the next lesson once the goal is met (both also
on the touch screen).

## Screen-specific keys

| Screen | DS | Original key | Effect |
|---|---|---|---|
| Title / main menu | SELECT | (menu entry) | cycle home screens you own |
| Tournament roadmap | hold L or R + ← → | Shift + ← → | jump 5 levels |
| Result screens (tournament, mission, ticket) | Y | R | retry the level/mission straight away |
| Shop | L / R (or SELECT) | ← → on the tab row | previous / next shop page |
| Workshop | Y | G | TANK STUDIO preview booth |
| Profiles | Y / X | R / X | rename / delete (press X twice) |
| On-screen keyboard | X / Y | Backspace / Space | delete / space |

## Text entry

Names, tank lore and cheat codes use an on-screen keyboard on the touch screen (digits, A–Z, `-`, `_`, `.`,
space, DEL, OK). Tap keys with the stylus; **B** cancels, **OK** confirms.

## Touch

* Lists: tap a row to highlight it, tap it again to choose it.
* Buttons drawn on the bottom screen (`[ A ] START`, `B BACK`, page arrows, RPS hands, the battle panel) are all
  tappable.
* The top screen is not touch-sensitive (DS hardware).
