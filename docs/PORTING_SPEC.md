# PORTING SPEC — Terminal Tanks (Python 1.5.0) → Nintendo DS

Source of truth: `reference/terminaltanks.py` (13,455 lines, single file, stdlib only, by ethanlabs101).
Line numbers below refer to that file. Everything here was read from the source; counts were verified by
importing the module (`tools/ttref.py`).

## 1. What the game is

Turn-based 2D artillery ("Scorched Earth"-style). Two or more tanks on a destructible column heightmap take
turns setting barrel angle and power and firing a shell that follows an analytic ballistic arc with gravity
and wind. A hit (direct, or a blast within splash reach) costs hearts; a tank at 0 HP is destroyed; a team
with no tanks left loses the round. Matches are best-of-N rounds on rotating maps.

The terminal renders a "pixel canvas" with half-block characters (two pixels per cell), so the battlefield is
a real pixel grid: **field width = terminal columns (max 180), field height = 2 × field rows (max 40 rows → 80 px)**
(`field_size`, l.10662). The DS port fixes the field at **128 × 80 px** (a legal 128×40 terminal field).

## 4. Simulation

### 4.1 Randomness
Python `random.Random` (MT19937). Calls used by gameplay: `random()`, `uniform(a,b)=a+(b-a)*random()`,
`randrange(n)` (rejection sampling on `getrandbits(bit_length(n))`), `randint`, `choice`, `gauss(mu,sigma)`
(cached-pair Box–Muller variant). Integer seeds → `init_by_array` of 32-bit words of |seed|.
Separate streams (all seeded from the session rng):
- `MatchSession.rng = Random(seed)`: map picks, round seeds, AI seeds (`randrange(1<<30)`).
- `BattleWorld.rng = Random(round_seed)`: terrain phases, spawn jitter, scenery (sky orb, ridge phases,
  stars, motes — **consumed even though they are visual**), initial wind, wind drift, streaks.
- `vrng = Random(seed ^ 0x5EED)`: particles only.
- `srng = Random(seed ^ 0xA11E)`: scene decisions (UFO hops, Martyr element choice, CPU special forfeits).
- `AIController.rng = Random(session.rng.randrange(1<<30))` per AI tank.
**Port rule:** reproduce every draw of the sim streams in the same order (including scenery draws).
**Known original quirk:** `ScreenShake.offset(w.rng, …)` draws from the *simulation* rng while drawing
frames (l.9376), so wind sequences depend on frame rate when screen effects are on. The DS port uses the
visual rng for shake (documented deviation; it also removes a latent LAN desync).

### 4.2 Terrain (l.1198–1285)
`heights[x]` integer column heights. Construction: 3 phases `uniform(0,2π)`; `scale=min(H, W*0.55)*0.74`;
`h = sample_profile(profile,u,smooth)` (+ roughness sines 7/17/41 cycles); `heights = int(clamp(h*scale+2, 2, H-10))`.
`sample_profile`: linear or Catmull-Rom (clamped ≥0.02). Operations: `flatten(cx,half)` (used at spawn, half=10),
`carve(cx,cy,r)` (circle), `mound(cx,r,h)`, `trench(cx,half,depth)`, `smooth(cx,r)` (glassing), `support_height(x)` =
min of heights in [x-5, x+5]. `scorch[]` tracks blackening.

### 4.3 World setup (`BattleWorld.__init__`, l.3743)
Per player: `jitter=uniform(-0.02,0.02)`; team slot k; `gap = 0.13` (0.18 if any scale≠1);
`frac = spawns[0]+k*gap` (team 0) or `spawns[1]-k*gap`; `x = int(clamp((frac+jitter)*W, 9+half, W-10-half))`;
`flatten(x+0.5,10)`; tank at `x+0.5`, `y = support_height(x)+hover`; facing +1/-1; angle 50 / 130.
Then Scenery (rng draws), `roll_wind`, `_make_streaks` (n = max(8, W*H//450), 2 draws each).

### 4.4 Wind
`roll_wind`: `round(choice((-1,1))*uniform(0.2,1)*m, 1)` (m = settings wind 0/3/6/10; GALE rule = 10).
`drift_wind` at every turn end: `round(clamp(w + uniform(-0.45,0.45)*m, -m, m), 1)`.
Wind is a constant horizontal acceleration `ax` on the shell.

### 4.5 Ballistics (l.3681–3737)
`max_speed = sqrt(g * W * 1.16)`; `speed = max_speed * clamp(power/100,0,1)`.
`Launch.at(t)`: `x = x0+vx t+½ax t²`, `y = y0+vy t-½g t²`; corkscrew `wa,wf` adds a sideways offset
`wa*sin(wf t)*min(1, 2.5t)` along the normal. Muzzle: `(x + d cos a, y + 4.5 + d sin a)`, `d = barrel_len + 1`
(big units: belly cannon). `trace(dt=0.02, max 12 s)`: probe each step; returns impact, points, time.
Collision: x outside [0,W) → OUT; `y < heights[int x]` → TERRAIN; inside any tank rect ± 0.9 → TANK.
Owner probe ignores the shooter until the shell has left its rect ± 1.5.

### 4.6 Shot planning (`plan_shot`, l.8376) — the full ammo mechanics
The whole shot is planned at fire time on the fixed 20 ms grid (deterministic, LAN-safe):
mech keys `g, wind, speed` (launch scaling), `wob=(amp,freq)`, `bounce=n, br`, `radius`, `dmg`,
`apex=("split",n,spread)|("jump",dist)`, `subr`, `cluster=n, cspace, cr`, `chain=n, cstep, cr`,
`fuse=seconds, fr`, `terrain=mound|trench|glass`, `pull`, `multi`. Exact formulas are ported verbatim in
`core/shot.c`. Mechanics are disabled when `ammo_fx` is off (Tournament, Missions, some rules) and for the
special attack (3 dmg, radius 2.0).

### 4.7 Impact resolution (`_start_event`/`_impact_update`, l.9028–9116)
Victims: direct tank hit → that tank; terrain hit → nearest alive tank(s) within `2.5*radius` (all if `multi`).
Timeline per event: explosion at t≥0, particles 0.06, terrain op at 0.28 (radius ×0.85 on direct hits),
damage at 0.42: `dmg * (2 if direct and target scale>1) * session.dmg_mult`; shields absorb one hit each.
Pull: tanks within `pull*2.2` move `clamp(dx*0.6, ±pull)`. Then settle (tanks fall at 45 px/s to support height).
Destruction: the round ends when a whole team is dead; teammates fight on.

### 4.8 Turn flow
Phases INTRO(1.8 s) → AIMING / AI_THINKING → FLIGHT → IMPACT → SETTLE → (DESTRUCTION) → next turn.
Order: teams alternate, starting team = `(round-1 + first_offset) % 2` (RPS decides `first_offset` in Two Player/LAN).
Angle 2..178 (±1, ±5 coarse), power 10..100. Special attack (rule): X forfeits the turn, 2 charges
(1 vs the Martyr) make the next shot the special. UFOs: hop each turn, shields at 66%/33% HP, every other turn
"charging", volley of 3 shots every 2–3 turns; the Mothership is shielded while drones live.
MARTYR'S BLESSING (secret ammo): a direct hit on an enemy kills every enemy (scripted 4-act spectacle with
real craters).

### 4.9 AI (l.3928–4129)
Profiles EASY/NORMAL/HARD/MASTER (angle σ, power σ, gravity error, sim dt, terrain awareness, learn rate,
think time, angle step, pick-from, refine, wind error, adaptive). Grid search rel angle 18..82 × power 22..100,
miss metric with history penalty; MASTER ensemble (8 candidates, 14 noisy rollouts each) and gravity-model bisection
after a miss. Execution noise via `gauss`. Tournament `precision` multiplies σ. Ported exactly in `core/ai.c`.

## 5. Modes and progression

- **Single Player**: rules screen (format, rounds, hearts, map, pick-next-map, wind, special ammo, blessing,
  special attack) → pilot setup (tank, hull colour, ammo, shell colour, AI difficulty) → match vs CPU (random
  starter kit, or the Master kit on MASTER). Pays `int(20*mult)` coins on win, 10 on loss.
- **Two Player** (hot-seat): rules → 2 setup pages → rock-paper-scissors → match. No coins.
- **LAN**: host/join, the host's rules; versus or co-op missions. **DS port: local wireless (see MULTIPLAYER.md).**
- **Tournament**: 20 levels, rules (standard / streak / flawless / onestrike / glass / gale); each clear unlocks the
  boss kit (+map/extras). Payout table l.4334. Master difficulty + MASTER home screen at level 20.
- **Missions** (open after level 20): 50 — marathon, 2v1, ufo, coop (local / LAN / AI wingman), rush, mothership.
- **Shop**: 5 pages × tiers; coins and credits; Terminal Tickets (10 vault bosses, open after L20 + M50);
  Martyr's Time Machine (after all tickets) → 3-phase Martyr fight with cinematics → ancient rewards + Blessing.
- **Workshop** (after L5): custom tanks from owned parts (2500 coins, hover +25000/+50cr), up to 24.
- **Tutorial**: 4 practice lessons, briefing, 3 challenges. **Cheat codes**, **Profiles** (3), **Settings**.

## 6. Save data (`SaveData`, l.4940)
JSON v5: completed levels (chain-validated), granted unlockables, missions completed/paid, tickets won/active,
story whispers, playtime, martyr state, custom tanks, wallet, two loadouts, settings strings. Legacy migrations
for v1–v3 saves. **DS port**: same logical fields, stored as a compact versioned binary on the SD card via
FAT (`/data/TerminalTanks/profile<N>.sav`) when available; otherwise the game runs with an in-memory save and the boot screen says "NO SD CARD / FAT ACCESS".

## 7. Hardware adaptations (summary — details in FEATURE_PARITY.md)
- Terminal cell renderer → native 16-bit framebuffers on both screens (battlefield 128×80 at 2×, bitmap font UI).
- Keyboard → DS buttons (+ touch on the bottom screen); text entry via an on-screen keyboard.
- TCP/UDP LAN → dswifi local multiplayer, same command protocol semantics.
- Terminal bell → simple PSG beeps (optional setting, as in the original).
- Visual effects keep their styles but are evaluated with fixed-point/LUT math where needed for speed.
